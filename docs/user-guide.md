# BidProof 使用手册（投标专员）

本页面向使用工作台的业务用户。部署与环境变量见 [README.md](../README.md)，接口见 [api-integration.md](api-integration.md)。

## 第一次登录

1. 打开工作台 `/app`。
2. 使用企业账号登录，或「个人注册」，或「试用加入」码。
3. 阅读 [隐私与数据处理说明](/privacy)（登录前即可打开）。

## 三步完成一次扫描

1. 点击「新建扫描」，选择项目，上传招标文件（必填）和企业证据（可选）。
2. 在作业页查看进度百分比与阶段文案；可离开页面，完成后回任务列表。
3. 打开任务：核对高风险项 → 人工复核 → 记录 CONTINUE / HOLD / STOP → 导出报告。

## 不要用本系统做的事

不代写标书、不自动报价、不提供法律意见、不代替你按下投标按钮。
