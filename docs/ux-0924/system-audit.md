# 0924 认知减负与认证改造

基线：用户提供的 BID_0924.zip。保留原压缩包及上一版本，在独立目录实现；不修改已上线服务。以下是改造前审计与实现路径，不代表已完成验收。

| 优先级 | 现状与影响 | 改造路径 |
| --- | --- | --- |
| P0 | 只有账号密码、邀请及企业 OIDC，没有邮箱/短信验证码链路 | 服务端配置驱动渠道；持久化一次性验证码、过期/尝试次数/频控，前端统一入口；保留 MFA 和工作区隔离 |
| P0 | 前端若仅新增按钮会出现不能交付的认证入口 | 真实 SMTP/Twilio/Google/GitHub 适配；未配置入口不展示；交付配置说明，不能把模拟发送当成功 |
| P1 | 首页标题抽象，价值、流程、定价、FAQ 等同时争夺注意力 | 结果标题 → 输入与结果演示 → 单个主要 CTA，下方仅三张用途卡片 |
| P1 | 空状态仅一个试跑按钮，三步说明不记录完成状态 | 两套明确标注的合成样例及自己的材料入口，可收起三步进度，仅在实际动作成功后推进 |
| P1 | 示例按钮先经 JSON 请求再二次 Blob 下载；默认 PDF 字体不能正确承载中文 | 统一 Blob 下载，样例使用中文字体并验证可提取文本；一次填入招标和证据文件 |
| P1 | 身份切换与延迟响应可能污染引导状态 | 绑定账号与会话代次，取消/过期时清理请求和临时数据；跨用户进度隔离 |

验证覆盖：落地页交互/键盘/减弱动效，认证状态与时间边界，OTP 单次使用/过期/频控/MFA，样例原文可读性，引导持久化与身份切换，既有 API 与前端回归。

上线仍需运营方配置并真实验收邮件/短信/OAuth 服务。合成样例不计入真实客户、OCR 准确率或业务验收。
