## 演示约束与状态

`ready → running → complete`。初始即显示静态结果，用户无须等待动画才理解用途。点击后，约 2.4 秒按“读取招标要求 → 对照企业材料 → 显示待办”完成一次演示；时间是演示节奏，不是实际扫描性能承诺。重复点击不会创建并发计时器。

演示为预置合成材料，不读取真实工作区、不请求审查 API、不写入存储、不自动核销。营业执照即使同时具备招标和证据页码，仍显示“待复核”。用户关闭动画偏好时直接显示结果；页面进入后台时结束当前演示并清理计时器。无 JavaScript 时结果及主按钮照常可用。

动态更新只使用 `textContent` 和 DOM 属性，避免富文本插入。可用键盘触发原生按钮，结果用一次 `role=status` 播报，读取中使用 `aria-busy`。输入材料内不含实际企业名称、客户标识或个人资料。

## 删减与样式决策

- 移除价格表、FAQ、四步流程、独立复杂演示、重复 CTA 和未验证信任数据。
- 移除英文眉题、轨道、旋转卡片、漂浮标注、滚动触发动效。
- 页面只保留白色表面、冷灰背景与深青操作色，风险提示使用低饱和红/琥珀。
- 主 CTA 为唯一大面积深青按钮；演示按钮使用描边，导航仅文本登录。
- 不加载远程图片、字体、跟踪 SDK；可选本地事件只携带固定 placement/action 枚举，不携带邮箱、材料或文本。
- SEO 与 OpenGraph 沿用服务器注入的 `__PUBLIC_ORIGIN__`，不写死演示域名；不引用不再代表当前页面的旧分享截图。
