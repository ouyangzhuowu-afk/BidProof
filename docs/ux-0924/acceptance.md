## 本轮实际发现并修复的边界

- SQLite 文件库原先共享一条连接，并发注册可能交叉提交，导致孤儿账号：改为独立连接，用户/工作区/绑定同事务，增加强制重叠注册回归。
- PostgreSQL 驱动不能依赖所有写入的 rowcount：验证码保留/消费及登录 flow 改用 SQL RETURNING，实库并发验证只成功一次。
- 旧示例重复下载且中文字体缺失：每类文件一次 Blob 下载，内置中文字体；真实提取器生成带页码的审查项。
- 首次验证码开户后的 MFA 隐藏字段与 bfcache 返回：清除过时字段和凭据，恢复时重新鉴权，测试确认只请求一次状态。
- 邮件发送故障、服务端限流与验证码过期：保留可恢复入口，以服务端 Retry-After 为准；不自动重试发送。
- 身份界面/API 禁止缓存与 Referrer 传播；动态文案仍经 SafeHtml 或 textContent。
