# Master Project Brief

## 项目身份

- 项目：Project-025 投标证据链 Agent
- 当前版本：MVP 0.2（产品楔子与证据契约）
- 目标用户：IT 服务、软件实施类中小企业的投标负责人
- 主要输入：中国公开采购文件（优先中文 PDF）和企业证据材料

## 核心目标

在不替用户作投标决策的前提下，扫描投标资格、废标/否决风险、评分项和关键日期，并将每条提示连接到招标文件或企业证据的页码原文。

## 成功标准

### 工程验收

- PDF 上传、页级文本/Layout 抽取、企业证据匹配、人工复核和任务删除可恢复运行。
- 确定性规则优先执行；模型只能产生候选抽取和解释，不能绕过证据门禁。
- `PASS` 必须同时具备要求项原文页码和企业证据原文页码；否则降级为 `UNKNOWN` 或 `NEEDS_REVIEW`。
- 每个结论包含来源文件、页码和原文 quote；冲突保留在 `contradiction_log`。
- 真实 fixture 验收目标：强制条件召回率 >= 97%、严重风险漏报率 <= 2%、页码可定位率 100%。未达标不得用措辞强度掩盖缺证据。

### 业务验证

- 45 天内接触 30 个明确 ICP。
- 完成 10 个真实任务。
- 获得至少 2–3 个付费意愿。
- 未达到门槛时暂停扩展功能，重新定义 ICP 或切换 RFQ 赛道。

## 明确不做

长标书自动生成、自动投标提交、自动报价、法律意见、跨行业规则库、生产部署、多租户商业化，以及任何未经验证的市场或法规承诺。

## 当前交付边界

- 已交付任务首页、扫描详情和人工决策三视图；首屏按资格/废标/日期/缺证据风险排序。
- 已交付来源文档、页级索引、要求项、证据资产、证据匹配、复核事件和决策记录的结构化字段，并保留旧 API 兼容读取。
- 已完成本地上传、历史任务恢复、筛选、复核、人工决策和删除接口；真实中文 PDF fixture 与业务试运行仍是外部依赖。

## 决策边界

最终投标决策由用户负责。本系统输出证据化风险提示和人工审批流，不输出“必然中标”“法律合规”或无页码的确定性结论。

## 证据等级

1. `VERIFIED`：原文可定位、规则或人工复核已确认。
2. `CANDIDATE`：规则或模型抽取的候选，尚未人工确认。
3. `UNKNOWN`：存在相关线索，但证据不足、冲突或无法定位。
4. `BLOCKED`：缺少必要输入、依赖或授权，不能继续。
